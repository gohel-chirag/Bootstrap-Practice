Bootstrap Components

Accordion

HTML (HyperText Markup Language) is used to create the structure of a webpage, such as headings, paragraphs, images, and buttons.

CSS (Cascading Style Sheets) is used to design and style the webpage by adding colors, fonts, spacing, and layouts.

JavaScript (JS) makes a webpage interactive by adding features like button clicks, animations, and form validation.

Bootstrap is a CSS framework that provides ready-made components and helps developers create responsive, mobile-friendly websites quickly and easily. Together, these four technologies help developers build attractive, interactive, and user-friendly websites.
